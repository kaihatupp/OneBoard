      予定を追加

      その月に無い日(31日など)はスキップされます。

      「地図で開く」を押すと Google マップに住所を送信します(押したときだけ)。

      発駅・着駅を入れると日別画面に「経路を調べる」(Yahoo!乗換案内)リンクが出ます。押したときだけ発着駅と日時を送信します。開始時刻があれば「到着時刻」として検索します。

      Yahoo!乗換案内の結果を貼り付けてから押すと、先頭に「発着時刻 / 乗換 / 運賃」の要約行を足します。

      繰り返し予定の削除

      この予定は繰り返し設定されています。

      データ

      この端末にだけ保存されます。書き出したファイルはこのパスフレーズが無いと開けません。 変更したら PC で書き出し直してください。

      パスフレーズを入れると自動で取得します。表示されないときはこのボタンを押してください。

      予定を編集したら押してください。暗号化 → data/oneboard.enc.json 更新 → git push まで自動(OneBoard起動.bat で起動中のときのみ)。

      自動反映を使わないときは、ダウンロードした oneboard.enc.json を data/ に置いて自分で git push します。

      ファイルから取り込み
      またはテキストを貼り付けて取り込み

      取り込むと、この端末の予定・タスク・設定はすべて置き換わります(捕捉メモは追記)。

      この PC にバックアップファイルが無いときの最終手段。GitHub Pages 上の data/oneboard.enc.json を直接取得して全置換します (パスフレーズ必須 / 確認あり)。
